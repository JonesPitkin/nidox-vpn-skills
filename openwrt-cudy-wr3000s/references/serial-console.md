# Серийная консоль Cudy WR3000S v1

## Назначение

UART позволяет читать ранний bootlog, входить в U-Boot, загружать initramfs по TFTP и диагностировать устройство, которое не поднимает сеть.

Открытие корпуса повреждает наклейку над винтом и может повлиять на гарантию.

## Распиновка UART

Контакты подписаны на PCB. Маркировка находится на верхней стороне платы под радиатором, а контактная площадка доступна снизу.

Использовать подписи платы:

- `GND`;
- `TX`;
- `RX`;
- `VCC` или `3.3V`.

Официальная страница не фиксирует надёжный порядок контактов в текстовом виде. Не определять порядок по фотографии другой модели. Проверять маркировку своей платы или мультиметром.

Соединение:

| Роутер | USB-UART |
|---|---|
| GND | GND |
| TX | RX |
| RX | TX |
| VCC/3.3V | не подключать |

## Настройки подключения

```text
Скорость: 115200 бод
Биты данных: 8
Чётность: нет
Стоп-биты: 1
Flow control: нет
Логический уровень: 3,3 В
```

Пример Linux:

```sh
picocom -b 115200 --databits 8 --parity n --stopbits 1 /dev/ttyUSB0
```

Или:

```sh
screen /dev/ttyUSB0 115200
```

## Вход в U-Boot

В первоначальной процедуре OpenWrt предлагается включить питание с нажатым Reset и удерживать его до входа в U-Boot shell. Наблюдать вывод консоли и не вводить команды стирания flash.

Для загрузки initramfs TFTP-сервер должен быть доступен по `192.168.1.88`, а файл называться `cudy3000s.bin`:

```text
tftpboot 0x46000000 cudy3000s.bin; bootm 0x46000000
```

Эта команда загружает образ в RAM. Перед постоянной записью проверить модель и sysupgrade-совместимость.

## Предупреждения по подключению

- Использовать только USB-UART с логикой 3,3 В.
- Не использовать настоящий RS-232: его уровни напряжения несовместимы.
- Не подключать VCC адаптера; роутер питать штатным блоком.
- Сначала соединить GND, затем TX/RX.
- Не допускать короткого замыкания щупами.
- Не паять при подключённом питании.
- Если вывод нечитаемый, сначала проверить скорость, GND и перекрёст TX/RX, а не менять напряжение.
- Не записывать окружение U-Boot и загрузочные разделы без резервной копии.

## Полезные признаки в bootlog

Искать:

- определение `MediaTek MT7981`;
- объём DRAM `256 MiB`;
- модель SPI-NAND;
- успешное подключение NMBM;
- подключение UBI;
- модель `Cudy WR3000S v1`;
- сообщения kernel panic, UBI error или unsupported NAND.

Для поздней ревизии с F50L1G41LC ожидается определение ESMT SPI NAND при поддерживаемой версии OpenWrt. У ранних устройств могут встречаться XMC XM25QH128C или GigaDevice F50L1G41LB.
