# archive

Каталог `archive/` используется для хранения файлов, которые не участвуют в основной работе репозитория, но пока не удаляются автоматически.

Сюда могут временно переноситься:

- служебные файлы macOS, например `.DS_Store`;
- архивы `*.zip`;
- другие побочные артефакты, которые не являются частью целевой структуры skills.

Файлы в `archive/` рекомендуется периодически пересматривать и либо удалять, либо переносить обратно только при наличии явной необходимости.
