# Установка OpenWrt на Cudy WR3000S v1

## Подготовка

1. Сверить надпись `WR3000S` и аппаратную версию `v1`.
2. Записать серийный номер и MAC-адреса с наклейки.
3. Если серийный номер начинается с производственного кода `2543` или более позднего кода, исключить OpenWrt 24.10.0–24.10.4.
4. Скачать переходный **Cudy Signed OpenWrt** для WR3000S v1 из официального каталога Cudy.
5. Скачать официальный `squashfs-sysupgrade.bin` профиля `cudy_wr3000s-v1`.
6. Сверить SHA256 образа по Firmware Selector или `sha256sums`.
7. Подключить компьютер кабелем к LAN-порту.
8. Отключить на компьютере автоматическое переключение на Wi-Fi и VPN.
9. Обеспечить стабильное питание на весь период прошивки.

Не использовать образы WR3000, WR3000H, WR3000P или WR3000E. Профиль `cudy_wr3000s-v1-ubootmod` не использовать в этой двухэтапной процедуре: для него нужна отдельная миграция загрузчика.

## Требования к версии прошивки

- Официальная поддержка устройства исторически начинается с OpenWrt 24.10.0.
- Для NAND ESMT F50L1G41LC исторический минимум — 24.10.5.
- Предпочитать актуальный стабильный релиз, доступный в Firmware Selector.
- Snapshot использовать только при наличии конкретной причины и плана восстановления.

По состоянию на 7 июня 2026 года использовать OpenWrt 25.12.4 либо, если нужна ветка 24.10, её последний old-stable выпуск 24.10.7. Перед установкой всё равно проверять Firmware Selector: номер релиза меняется.

## Установка переходной прошивки Cudy Signed OpenWrt

1. Включить роутер со штатной Cudy firmware.
2. Пройти начальный мастер Cudy:
   - режим Wireless Router;
   - правильный часовой пояс;
   - WAN через DHCP, если нет других требований.
3. Открыть `http://192.168.10.1/`.
4. Перейти в `Advanced Settings` → `Firmware`.
5. Выбрать подписанный переходный образ именно для WR3000S v1.
6. Запустить обновление и не отключать питание.
7. Дождаться полного перезапуска.

После этого адрес управления меняется на `http://192.168.1.1/`. Wi-Fi может быть отключён, поэтому продолжать по Ethernet.

## Переход на официальный OpenWrt

1. Открыть LuCI на `http://192.168.1.1/`.
2. Перейти в `System` → `Backup / Flash Firmware`.
3. Загрузить официальный файл вида:

   ```text
   openwrt-<version>-mediatek-filogic-cudy_wr3000s-v1-squashfs-sysupgrade.bin
   ```

4. Проверить, что LuCI распознала совместимость устройства.
5. **Не сохранять настройки** переходной прошивки.
6. Запустить прошивку и дождаться перезагрузки.
7. Повторно открыть `http://192.168.1.1/`.

Если LuCI требует принудительно прошить несовместимый образ, остановиться и перепроверить модель и имя файла. Не использовать `force` как обычный этап.

## Обновление через Sysupgrade

После перехода на официальный OpenWrt обновлять обычным способом через LuCI или SSH.

Через LuCI:

1. Создать резервную копию конфигурации.
2. Загрузить новый `squashfs-sysupgrade.bin` для того же профиля.
3. Решить, сохранять ли настройки. Между обычными совместимыми релизами это допустимо, но после крупных изменений или при подозрении на старую конфигурацию лучше начать чисто.

Через SSH:

```sh
sysupgrade -T /tmp/openwrt-...-squashfs-sysupgrade.bin
sysupgrade /tmp/openwrt-...-squashfs-sysupgrade.bin
```

Первая команда только проверяет образ. Не применять `-F` без документированной необходимости.

## Проверка успешной установки

Проверить:

```sh
ubus call system board
cat /etc/openwrt_release
cat /proc/mtd
ip link show
logread | grep -Ei 'nand|ubi|mt76|error|fail'
```

Ожидаемые признаки:

- модель `Cudy WR3000S v1`;
- профиль платы `cudy,wr3000s-v1`;
- порты `wan`, `lan1`, `lan2`, `lan3`, `lan4`;
- UBI монтируется без критических ошибок;
- обе радиосистемы видны;
- LAN выдаёт адрес из `192.168.1.0/24`;
- WAN получает адрес согласно выбранному протоколу.

Сразу задать пароль root и настроить Wi-Fi: в чистом OpenWrt беспроводная сеть обычно отключена.

## Возможные ошибки

### Cudy GUI отклоняет файл

Вероятно, выбран обычный официальный OpenWrt вместо подписанного переходного образа либо файл предназначен для другой модели.

### После первого этапа нет Wi-Fi

Это ожидаемо. Подключиться кабелем и открыть `192.168.1.1`.

### После второго этапа LuCI недоступна

Проверить получение DHCP-адреса, вручную назначить адрес `192.168.1.2/24`, проверить `ping 192.168.1.1`, затем SSH. Если система загружается, но конфигурация повреждена, использовать Reset или Failsafe Mode.

### Образ объявлен несовместимым

Не нажимать принудительную прошивку. Проверить наличие `wr3000s`, суффикса `v1`, целевой платформы `mediatek-filogic` и типа `sysupgrade`.

### Поздняя NAND не определяется

Установлена версия без драйвера ESMT F50L1G41LC. Перейти к OEM TFTP recovery или UART по [recovery.md](recovery.md), затем использовать 24.10.5 или новее; предпочтительно текущие 24.10.7 или 25.12.4.

### Обновление прервано

Не выполнять многократные случайные перезагрузки. Сначала проверить поведение LED и доступность сети, затем выбрать Failsafe, OEM TFTP recovery или UART.
