# Светодиоды Cudy WR3000S v1

## Общая картина

OpenWrt Techdata указывает 10 физических LED. Официальный DTS описывает пять управляемых системных функций. Полная таблица всех десяти физических индикаторов и их GPIO на странице устройства не опубликована, поэтому не назначать неизвестные GPIO экспериментально.

## Индикаторы, описанные OpenWrt

| Функция | Цвет | GPIO | Назначение |
|---|---|---:|---|
| Status | белый | 10, active-low | загрузка, работа, Failsafe, обновление |
| Internet/WAN online | белый | 11, active-low | логическая функция WAN online |
| WPS | белый | 9, active-low | WPS |
| WLAN 2,4 ГГц | белый | 6, active-low | активность `phy0` |
| WLAN 5 ГГц | белый | 7, active-low | активность `phy1` |

Имена в `/sys/class/leds/` могут отличаться между релизами. Получать фактический список командой:

```sh
ls -1 /sys/class/leds
```

## Значения сигналов

### Status

Status LED связан с системными псевдонимами:

- `led-boot`;
- `led-failsafe`;
- `led-running`;
- `led-upgrade`.

Типичная интерпретация:

- изменение режима мигания при старте: boot;
- быстрое мигание: окно или активный Failsafe Mode;
- стабильный рабочий шаблон: система запущена;
- мигание во время прошивки: не отключать питание.

Точный шаблон задаётся версией OpenWrt и `/etc/diag.sh`.

### WLAN 2,4 и 5 ГГц

По умолчанию связаны с триггерами пропускной активности `phy0tpt` и `phy1tpt`. Мерцание показывает трафик радио, а не обязательно наличие доступа в интернет.

### Internet/WAN

DTS назначает этому LED функцию `WAN_ONLINE`, но фактический trigger следует проверять в `/sys/class/leds/<имя>/trigger`. Горящий индикатор не доказывает доступность конкретного сайта, корректность DNS или работу Podkop.

### WPS

Используется WPS-службой или пользовательским LED trigger. В безопасной домашней конфигурации WPS часто отключают.

## Индикаторы Ethernet

Wiki сообщает, что поддержка LAN LED штатно не завершена. Существуют пользовательские настройки LED triggers, но их нужно сверять с текущим релизом и не принимать за часть официального профиля.

Для диагностики Ethernet надёжнее использовать:

```sh
ip -br link
ubus call network.device status '{"name":"lan1"}'
ethtool lan1
```

Повторить для `lan2`, `lan3`, `lan4` и `wan`. Команда `ethtool` требует одноимённый пакет и может отсутствовать в базовом образе.

## Диагностика по светодиодам

| Наблюдение | Возможное состояние | Следующий шаг |
|---|---|---|
| Status меняет режим, затем стабилизируется | kernel и userspace стартуют | проверить DHCP, ping и SSH |
| Status быстро мигает после нажатия Reset | Failsafe Mode | назначить `192.168.1.2/24` и подключиться |
| Status остаётся в раннем состоянии | проблема загрузки или flash | подключить UART |
| WAN LED горит, интернета нет | физический линк есть, ошибка DHCP/PPPoE/DNS/routing | проверить `ifstatus wan`, DNS и маршруты |
| WLAN LED не активен | радио выключено или интерфейс не поднят | проверить `wifi status` и `logread` |
| LAN LED не работает, связь есть | ограничение поддержки LED | проверять DSA-интерфейс программно |

Не делать вывод о повреждении роутера только по одному индикатору.
