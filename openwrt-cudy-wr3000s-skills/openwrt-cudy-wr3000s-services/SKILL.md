# WR3000S Services

Use this skill when the task is not about flashing or recovery, but about using `Cudy WR3000S v1` as a services platform for Podkop, sing-box, routing policy, DNS, or FakeIP.

## Covers

- Podkop and sing-box fit on this hardware
- DNS and FakeIP service boundaries
- performance expectations and memory constraints
- safe rollout sequencing for VPN and proxy features
