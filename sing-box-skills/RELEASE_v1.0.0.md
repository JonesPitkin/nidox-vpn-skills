# Release v1.0.0

Initial public release of `sing-box-skills`.

## Highlights

- standalone AI skill repository for `sing-box`
- official-source-only knowledge base
- stable production baseline on `sing-box v1.13.13`
- production-oriented skills for:
  - architecture
  - DNS
  - inbounds
  - outbounds
  - routing
  - TUN
  - rule sets
  - security
  - OpenWrt
  - troubleshooting
- added skill index, version matrix and migration guide
- prepared repository for GitHub publication and integration into `nidox-vpn-skills`

## Source Policy

This release intentionally uses only:

- official `sing-box` documentation
- official SagerNet repositories
- official releases and migration material

## Version Baseline

- stable baseline: `v1.13.13`
- `1.14` treated as official future/alpha direction, not default production truth
