# Правила добавления Skills

## Обязательная структура

Каждый новый Skill должен иметь:

- `README.md`
- `references/`
- `agents/`
- `SKILL.md`

## Обязательный аудит

Перед включением в `nidox-vpn-skills` Skill должен пройти аудит через:

- `nidox-vpn-detection-defense-skill`

## Обновление индексных файлов

Новые Skills должны быть добавлены в:

- `SKILL_INDEX.md`
- `ROADMAP.md`
