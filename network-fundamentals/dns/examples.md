# Примеры DNS

## Пример 1. Рекурсивное разрешение

Пользователь открывает `www.example.com`. Локальный клиент спрашивает резолвер провайдера или публичный resolver. Тот по кэшу или через итеративные запросы находит A/AAAA-запись.

## Пример 2. Проблема только по именам

```sh
ping 1.1.1.1        # работает
ping example.com    # не работает
dig example.com     # timeout
```

Вероятнее всего проблема связана не с общей IP-связностью, а с DNS.

## Пример 3. Авторитативная ошибка

`dig @1.1.1.1 example.com` возвращает `SERVFAIL`, а `dig NS example.com` показывает неверные NS или сломанную DNSSEC/зону. Это уже не проблема пользователя, а проблема домена.
