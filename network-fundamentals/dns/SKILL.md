# DNS

Использовать этот раздел, когда проблема выглядит как "Интернет есть, но сайты по именам не открываются", а также когда нужно объяснить различие между recursive resolver и authoritative nameserver.

## Простое объяснение

DNS переводит доменные имена в IP-адреса. Без DNS человеку пришлось бы помнить IP каждого сервиса.

## Техническое объяснение

DNS - прикладной распределенный и иерархический протокол, стандартизованный в RFC 1034 и RFC 1035. Клиент обычно обращается к рекурсивному резолверу, а тот уже взаимодействует с root, TLD и авторитативными серверами, используя кэш и последовательность запросов.

## История

- DNS пришел на смену централизованным hosts-файлам.
- RFC 1034 и RFC 1035 остаются базовыми документами архитектуры и протокольной формы.

## Компоненты

- stub resolver на клиенте
- recursive resolver
- root servers
- TLD servers
- authoritative nameserver
- zone
- record types
- caching
