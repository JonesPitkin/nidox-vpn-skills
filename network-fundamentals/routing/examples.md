# Примеры routing

## Пример 1. Статический маршрут в филиал

```text
сеть филиала: 10.20.30.0/24
next hop: 192.168.100.2
```

Маршрут вручную добавляется на пограничный роутер. Пока топология стабильна, это простой и надежный вариант.

## Пример 2. Default route

Если у домашнего роутера нет знания о тысячах внешних сетей, он использует один маршрут по умолчанию в сторону провайдера.

## Пример 3. Асимметрия

Пакет уходит через один WAN, а ответ возвращается через другой и ломается stateful firewall/NAT.

## Частые команды

```sh
ip route
ip route get 8.8.8.8
traceroute 8.8.8.8
```
