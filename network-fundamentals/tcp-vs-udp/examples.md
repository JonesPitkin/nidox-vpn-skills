# Примеры TCP vs UDP

## Пример 1. DNS lookup

- Клиент отправляет короткий UDP-запрос на `53/udp`.
- Если ответ слишком большой или требуется zone transfer, возможен TCP.

## Пример 2. Видеозвонок

Потеря части пакетов лучше, чем накопление задержки из-за повторов. Поэтому медиапотоки часто идут поверх UDP.

## Пример 3. SSH

SSH требует корректной последовательности байт и надежности. Потерянный байт ломает сессию, поэтому TCP подходит лучше.

## Частые команды

```sh
ss -tn
ss -un
tcpdump -ni any 'tcp port 22'
tcpdump -ni any 'udp port 53'
nc -vz example.com 443
dig example.com
```

## Типичный инцидент

Сервис мониторинга отправляет telemetry по UDP и часть событий пропадает при перегрузке WAN. Это не "сломанный сервер" по умолчанию - это может быть ожидаемое поведение ненадежного транспорта под нагрузкой.
