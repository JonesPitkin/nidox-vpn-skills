# Примеры MTU

## Пример 1. PPPoE

Если поверх Ethernet используется PPPoE, доступный payload уменьшается. Типовой MTU становится меньше 1500, и без учета этого возможны подвисания некоторых TCP-сессий.

## Пример 2. WireGuard через домашний роутер

Наружный интерфейс имеет MTU 1500, но поверх него идет туннель с дополнительными заголовками. Эффективный путь меньше 1500. Если не настроить корректный MTU/MSS, часть трафика будет идти с потерями.

## Пример 3. Проверка большого ping

```sh
ping -M do -s 1472 8.8.8.8
tracepath 8.8.8.8
```

Если `ping` с `-M do` не проходит, а меньший размер проходит, по пути есть меньший MTU или блокировка ICMP.

## Реальный сценарий использования

После включения туннеля пользователь жалуется: "открываются только простые сайты". Часто это не DNS, а именно MTU/PMTUD black hole.
