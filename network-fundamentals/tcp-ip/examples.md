# Примеры TCP/IP

## Сценарий 1. Доступ к веб-сайту

```text
браузер
  -> DNS определяет IP
  -> TCP устанавливает соединение с 443/tcp
  -> IP доставляет пакеты через маршрутизаторы
  -> HTTP/TLS обмениваются данными приложения
```

## Сценарий 2. Почему ping не равен "сайт работает"

- `ping` проверяет IP-достижимость, а не HTTP.
- Сайт может не открываться из-за DNS, TCP/443, TLS, reverse proxy или приложения.

## Частые команды

```sh
ping 1.1.1.1
traceroute 1.1.1.1
ss -tn state established
curl -I https://example.com
dig example.com
```

## Частый реальный кейс

Пользователь говорит: "VPN подключен, но сайт не грузится".

Разбор:

- IP-туннель может быть поднят.
- TCP route back может быть сломан.
- DNS может идти не через нужный resolver.
- MTU может резать большие TCP-сегменты.
