# Gateway

Использовать этот раздел, когда нужно объяснить, как хост выходит за пределы своей подсети и почему неверный default gateway ломает Интернет даже при корректном IP-адресе.

## Простое объяснение

Шлюз по умолчанию - это адрес маршрутизатора, которому хост отправляет пакеты для всех сетей, не находящихся в его собственной подсети.

## Техническое объяснение

Хост сначала определяет, находится ли destination IP в локальном prefix. Если да, он ищет MAC соседа и отправляет кадр напрямую. Если нет, он использует default route и отправляет кадр на MAC шлюза.

## История

- Понятие gateway исторически тесно связано с ранней IP-маршрутизацией.
- В Cisco-материалах default route и gateway of last resort - базовые элементы практики.
