# Примеры gateway

## Пример 1. Неверный gateway от DHCP

Клиент получил `192.168.1.50/24`, но gateway `192.168.2.1`. Локальные хосты работают, Интернет не работает.

## Пример 2. Доступ к локальному серверу без gateway

Если сервер и клиент находятся в одной подсети, они могут общаться напрямую без участия gateway.

## Частый вопрос

### Почему я пингую соседний адрес, хотя gateway сломан?

Потому что для той же подсети трафик идет напрямую, не через default gateway.
