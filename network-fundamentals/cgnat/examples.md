# Примеры CGNAT

## Пример 1. Проброс порта не работает

Пользователь настроил `443 -> 192.168.1.20:443` на домашнем роутере, но снаружи сервис недоступен. WAN роутера имеет `100.64.23.10`, а внешний сервис показывает `198.51.100.77`. Это типичный признак CGNAT.

## Пример 2. VPN-сервер дома

Домашний WireGuard-сервер не принимает входящие пакеты из Интернета при наличии CGNAT. Решения:

- запросить публичный IPv4;
- использовать IPv6;
- поднять сервер на VPS и строить tunnel к нему.

## Частый вопрос

### Почему веб-сайты могут работать, а входящие подключения нет?

Потому что исходящие соединения CGNAT пропускает через свои таблицы трансляции, а unsolicited inbound без созданного state обычно некуда доставлять.
