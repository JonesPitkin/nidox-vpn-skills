# Примеры NAT

## Пример 1. Домашняя сеть

Десять устройств с адресами `192.168.1.0/24` выходят в Интернет через один публичный адрес провайдера. На границе выполняется PAT.

## Пример 2. Публикация веб-сервера

```text
203.0.113.5:443
  -> DNAT
192.168.1.20:443
```

Чтобы это работало, нужны:

- корректный DNAT;
- разрешение входящего трафика firewall;
- маршрут возврата через тот же маршрутизатор.

## Частые вопросы

### Почему с мобильного Интернета нельзя открыть мой домашний сервис?

Возможные причины: нет проброса порта, двойной NAT, CGNAT, firewall drop, сервис слушает не тот адрес.
