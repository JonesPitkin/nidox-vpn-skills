# OpenWrt / Cudy WR3000S

Этот каталог зарезервирован для skills по `OpenWrt / Cudy WR3000S` внутри `nidox-vpn-skills`.

Если соответствующие материалы используются в этом мета-репозитории, они входят в общую VPN-систему и должны проходить аудит через `nidox-vpn-detection-defense-skill`.

Существующие локальные материалы в корне репозитория сохранены и могут быть позже приведены к этой структуре без удаления текущих файлов.
